# Vault Operating Conventions

- `company/COMPANY.md`: Company mission, tone, products, and policies.
- `teams/<slug>/TEAM.md`: Team mandate and shared guidance.
- `agents/<slug>/AGENT.md`: Role configuration (YAML frontmatter) and instructions.
- `agents/<slug>/notes/NOTES.md`: Agent private working notes (<= 80 lines).
- `agents/<slug>/artifacts/`: Deliverables and generated files.
- `memory/`: Owner-verified facts and memory index.
- `wiki/` and `sources/`: Shared cited knowledge and raw references.
