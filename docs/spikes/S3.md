## Số đo

- **Kích thước gói Client SPA (`build/_app/immutable/`)**:
  - **Trước khi import icon**: `14` files JS = `97,694 B` raw (**`38,494 B` / `37.59 KB` gzip**) \| `1` file CSS (Tailwind 4 + `tokens.css` + khai báo `@font-face` Inter) = `19,624 B` raw (**`4,719 B` / `4.61 KB` gzip**).
  - **Sau khi import `CircleCheck` (cả barrel lẫn subpath)**: `14` files JS = `111,758 B` raw (**`43,963 B` / `42.93 KB` gzip**, chênh `+5.34 KB` gzip cho runtime `<Icon>` dùng chung một lần duy nhất).
- **Thời gian build Production (`bun run build` với Vite 8 Rolldown)**:
  - Import từ gốc `@lucide/svelte`: `4.643` modules -> **`4.16 s`**.
  - Import theo subpath `@lucide/svelte/icons/<ten-icon>`: `148` modules -> **`0.286 s`** (nhanh hơn **`14.5x`**).
- **Độ trễ sự kiện SSE (`/api/v1/events` -> UI `$state` DOM trên loopback)**:
  - Go HTTP stream: **`0 – 1 ms`**.
  - Trình duyệt Chrome Headless (`EventSource` -> `$state` -> cập nhật text DOM): **`4 ms`** (ngưỡng yêu cầu `< 200 ms`).
  - Tailscale Serve: máy chạy kiểm thử không cài Tailscale nên ghi nhận kết quả loopback.

## Quyết định

- **Cấu hình chuẩn chốt cho `web/` ở Phase 1 (`P1.25`, `P1.31`)**:
  - Cấu hình `adapter-static` trực tiếp bên trong `vite.config.ts` (chuẩn SvelteKit 3):
    ```ts
    sveltekit({
      adapter: adapter({ pages: 'build', assets: 'build', fallback: 'index.html', precompress: false, strict: true })
    })
    ```
  - Đặt `export const ssr = false; export const prerender = false;` tại `src/routes/+layout.ts`.
  - Nhúng `web/build` vào Go bằng `//go:embed all:web/build`; mọi đường dẫn bắt đầu bằng `/api/` không khớp route trả `404 JSON`, các đường dẫn còn lại nếu không khớp file tĩnh thì trả `index.html` (`Cache-Control: no-cache`, các chunk băm trong `/_app/immutable/` giữ cache dài hạn).
  - Với menu `popover="auto"`, luôn tính tọa độ `top`/`left` (`position: fixed; margin: 0`) bằng `triggerEl.getBoundingClientRect()` trong sự kiện `ontoggle` (`ev.newState === 'open'`), tránh phụ thuộc CSS Anchor Positioning vốn chưa đồng nhất hoàn toàn trên Firefox/Safari.

## Việc phải sửa trong spec/kế hoạch

1. **Cập nhật 4 thay đổi bắt buộc của SvelteKit 3 cho task `P1.25` (Khung UI)**:
   - **Không tạo file `svelte.config.js`**: SvelteKit 3 báo lỗi `config_file_unsupported` nếu tồn tại `svelte.config.js`; toàn bộ cấu hình đặt trong `sveltekit({ ... })` ở `vite.config.ts`.
   - **Peer dependencies**: `@sveltejs/kit` 3.x yêu cầu **`vite@^8.0.12`** (Vite 8 Rolldown) và **`typescript@^6.0.0`** (Vite 7 sẽ gãy lỗi thiếu `parseSync`).
   - **`tsconfig.json`**: Kế thừa `"extends": "$app/tsconfig"` (thay vì `"./.svelte-kit/tsconfig.json"` cũ).
   - **Alias `#lib/*` thay cho `$lib/*`**: SvelteKit 3 đã gỡ `$lib` mặc định (`module_removed_lib`) để chuyển sang chuẩn Node subpath imports trong `package.json`: `"imports": { "#lib/*": "./src/lib/*" }` (khi import ghi kèm đuôi `.js`/`.svelte`, ví dụ `import { liveEvents } from '#lib/events.svelte.js'`). Cập nhật các đường dẫn trong kế hoạch `P1.25`–`P1.31` sang `#lib/...`.
2. **Quy ước bắt buộc import icon theo subpath (`Spec 8.13.1` / `P1.31`)**: Quy định mọi nơi trong `web/` import icon theo đường dẫn con `import CircleCheck from '@lucide/svelte/icons/circle-check'` thay vì barrel `import { CircleCheck } from '@lucide/svelte'` để giữ thời gian build Vite ở mức `~0.3s` thay vì `> 4s` mỗi lần biên dịch 4.500 file icon.
3. **Định vị phần tử `[popover]` cho component `Menu` (`Spec 8.13.1` / `P1.31`)**: Phần tử HTML `<div popover="auto">` mặc định nằm căn giữa màn hình (top-layer); trong component `Menu.svelte` ở `P1.31`, giữ nguyên thuộc tính gốc `popover="auto"` để trình duyệt tự xử lý lớp nổi + đóng bằng phím `Esc`/click ngoài, kết hợp hàm định vị `getBoundingClientRect()` (kèm kẹp biên `window.innerWidth`/`innerHeight`) khi mở menu.
